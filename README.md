### 📐 Senior Engineering Non-Negotiables

- **Type Contracts Across Boundaries**: No implicit `any`. Strict data serialization validation with Zod / Pydantic across all network and persistence layers.
- **Defensive API Design**: Idempotent operations for mutation endpoints, structured HTTP error schemas, and distributed rate-limiting.
- **Security-First Architecture**: Principle of Least Privilege (PoLP), constant OWASP Top 10 mitigation audits, sanitized inputs, and encrypted secrets management.
- **Maintainable Simplicity**: Avoiding microservice fragmentation when a cleanly modularized monolith is more reliable, observable, and cost-effective.
